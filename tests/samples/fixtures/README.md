# Sample metadata fixtures

These tiny files are used only by the test sample generator
(`tests/samples/make_samples.py`) to build Dolby Vision test videos.

| File            | What it is                                       |
|-----------------|--------------------------------------------------|
| `profile8.bin`  | One Dolby Vision profile 8.1 metadata frame (RPU) |
| `profile5.bin`  | One Dolby Vision profile 5 metadata frame (RPU)   |
| `fel_orig.bin`  | One Dolby Vision profile 7 (FEL) metadata frame   |

Copied from the test assets of [dovi_tool](https://github.com/quietvoid/dovi_tool)
(commit 41dae646), MIT License, Copyright (c) quietvoid.
